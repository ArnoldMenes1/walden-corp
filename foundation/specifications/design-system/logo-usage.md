# Objectif

Le présent document définit les règles officielles d'utilisation du logo **Walden Corp**.

Son objectif est de garantir une utilisation :

- cohérente ;
- professionnelle ;
- uniforme ;
- lisible ;
- reconnaissable ;
- conforme à l'identité visuelle de Walden Corp.

Ces règles s'appliquent à tous les supports de communication de l'entreprise, notamment :

- sites web ;
- applications ;
- réseaux sociaux ;
- documents administratifs ;
- présentations ;
- documents commerciaux ;
- supports marketing ;
- documents imprimés ;
- interfaces logicielles ;
- produits numériques ;
- signatures électroniques ;
- supports institutionnels ;
- documents produits par des collaborateurs, partenaires ou prestataires.

Le respect de ces règles est obligatoire pour toute utilisation officielle du logo.

---

# Principe fondamental

Le logo constitue un élément essentiel de l'identité visuelle de **Walden Corp**.

Il doit être utilisé comme un élément graphique **stable, identifiable et non modifiable**.

> **Le logo ne doit jamais être redessiné, interprété, transformé ou adapté librement.**

Toute utilisation doit préserver :

1. ses proportions ;
2. sa construction ;
3. ses couleurs ;
4. sa typographie ;
5. son espacement ;
6. sa lisibilité ;
7. son intégrité graphique.

---

# 3. Versions officielles du logo

Walden Corp dispose de **six versions officielles**.

Aucune autre déclinaison ne doit être considérée comme officielle sans validation préalable.

## 3.1 Logo principal — Horizontal

Le logo horizontal constitue la **version de référence** de Walden Corp.

Il doit être privilégié lorsque l'espace disponible permet une présentation horizontale confortable.

### Utilisations recommandées

- site web ;
- en-tête de documents ;
- présentations ;
- documents commerciaux ;
- signatures ;
- factures ;
- contrats ;
- supports institutionnels ;
- documents numériques.

### Priorité

**Version à privilégier par défaut.**

---

## 3.2 Logo vertical

La version verticale est destinée aux espaces où la composition horizontale n'est pas adaptée.

Elle peut notamment être utilisée sur :

- formats carrés ;
- couvertures ;
- affiches ;
- supports sociaux ;
- espaces verticaux ;
- certains supports imprimés.

La version verticale doit conserver exactement les proportions et les éléments définis dans le logo officiel.

---

## 3.3 Icône seule

L'icône seule correspond au symbole graphique du logo sans le nom complet de l'entreprise.

Elle est réservée aux environnements où l'espace disponible est limité.

### Utilisations recommandées

- favicon ;
- application mobile ;
- icône d'application ;
- avatar ;
- photo de profil ;
- réseaux sociaux ;
- interface logicielle ;
- petit format digital ;
- éléments de navigation.

L'icône ne doit pas être reconstruite manuellement à partir du logo complet.

---

## 3.4 Version couleur

La version couleur constitue la principale expression visuelle de la marque.

Elle utilise principalement :

- **Bleu nuit : `#0F2052`**
- **Blanc : `#FFFFFF`**

Elle doit être utilisée en priorité sur des fonds permettant un contraste suffisant.

---

## 3.5 Version noire

La version noire est destinée aux situations nécessitant une représentation monochrome.

### Utilisations possibles

- documents administratifs ;
- impressions monochromes ;
- documents internes ;
- photocopies ;
- certains supports professionnels ;
- applications nécessitant une seule couleur.

La version noire ne doit pas être utilisée comme remplacement arbitraire de la version couleur.

---

## 3.6 Version blanche

La version blanche est destinée aux fonds sombres ou suffisamment contrastés.

Elle peut être utilisée notamment sur :

- fond noir ;
- fond bleu nuit ;
- supports sombres ;
- certaines compositions institutionnelles.

La version blanche doit rester parfaitement lisible.

---

## 3.7 Règle de sélection

| Situation | Version recommandée |
|---|---|
| Espace horizontal standard | Logo horizontal |
| Espace vertical ou carré | Logo vertical |
| Favicon | Icône seule |
| Application mobile | Icône seule |
| Réseaux sociaux | Icône ou version adaptée |
| Fond clair | Version couleur |
| Impression monochrome | Version noire |
| Fond sombre | Version blanche |

> **Aucune version non listée dans ce document n'est considérée comme officielle.**

Toute nouvelle déclinaison doit être validée par la direction de Walden Corp.

# 4. Zone de protection

Une zone de protection doit obligatoirement être maintenue autour du logo.

Cette zone garantit que le logo reste visuellement indépendant des autres éléments graphiques.

## 4.1 Module de référence

La zone de protection est définie à partir de la **hauteur du losange central du "W"**.

Ce module constitue l'unité de mesure officielle.

Notons cette unité :

**X = hauteur du losange central du "W"**

La zone minimale de protection doit être égale à :

**X**

sur les quatre côtés du logo.

---

## 4.2 Éléments interdits dans la zone

Aucun élément ne doit pénétrer dans la zone de protection, notamment :

- texte ;
- photographie ;
- illustration ;
- icône ;
- bouton ;
- bordure ;
- autre logo ;
- élément décoratif ;
- forme graphique ;
- ligne ;
- objet d'interface.

### Schéma conceptuel

```text
              X
        ┌───────────────┐
        │               │
        │   ZONE LIBRE  │
        │               │
    X   │    LOGO       │   X
        │               │
        │               │
        └───────────────┘
              X
````

La zone de protection doit être conservée même lorsque le logo est placé à proximité d'un autre élément de marque.

---

# 5. Taille minimale

La taille minimale garantit que le logo reste lisible et identifiable.

## 5.1 Utilisation digitale

### Logo complet

**Largeur minimale : 24 px**

### Icône seule

**Largeur minimale : 16 px**

Ces dimensions constituent les seuils minimums recommandés pour les interfaces numériques.

---

## 5.2 Utilisation imprimée

### Logo complet

**Largeur minimale : 15 mm**

En dessous de cette dimension, la lisibilité du nom et des détails graphiques peut être compromise.

---

## 5.3 Règle de redimensionnement

Lorsqu'un logo est redimensionné :

* conserver les proportions ;
* ne jamais modifier indépendamment la hauteur et la largeur ;
* utiliser un redimensionnement proportionnel ;
* conserver la zone de protection ;
* vérifier la lisibilité après réduction.

> **La taille peut être réduite ou augmentée, mais les proportions du logo doivent toujours rester identiques.**

# 7. Fonds autorisés

Le logo doit toujours être placé sur un fond garantissant sa lisibilité.

## 7.1 Fonds recommandés

Les fonds suivants sont autorisés :

* fond blanc ;
* fond noir ;
* fond bleu nuit `#0F2052` ;
* fond uni suffisamment contrasté ;
* fond neutre clair ;
* fond neutre sombre lorsque la version blanche est utilisée.

---

## 7.2 Fonds complexes

Les fonds photographiques ou complexes doivent être évités.

Une photographie peut uniquement être utilisée lorsque :

1. le contraste est suffisant ;
2. le logo reste immédiatement identifiable ;
3. aucun élément important de la photographie ne traverse la zone de protection ;
4. aucune partie du logo n'est masquée.

Lorsque ces conditions ne peuvent pas être respectées, le logo doit être placé sur une zone unie ou dans un conteneur approprié.

---

# 8. Contraste et lisibilité

Le contraste entre le logo et son environnement doit toujours être suffisant.

## 8.1 Sur fond clair

Utiliser prioritairement :

**Logo couleur**

ou

**Logo noir**

---

## 8.2 Sur fond sombre

Utiliser prioritairement :

**Logo blanc**

---

## 8.3 Sur fond bleu nuit

Utiliser :

**Version blanche**

afin de maintenir une séparation visuelle claire.

---

## 8.4 Fonds à faible contraste

Les situations suivantes doivent être évitées :

* logo bleu nuit sur bleu clair proche ;
* logo noir sur gris foncé ;
* logo blanc sur gris clair ;
* logo placé sur une photographie très détaillée ;
* logo placé sur un motif répétitif ;
* logo placé sur un dégradé créant une perte de contraste.

> **La priorité absolue est toujours la lisibilité.**

---

# 9. Utilisations interdites

L'intégrité du logo doit être préservée en toutes circonstances.

Les modifications suivantes sont strictement interdites.

---

## 9.1 Déformation

Il est interdit :

* d'étirer le logo horizontalement ;
* de l'étirer verticalement ;
* de le compresser ;
* de modifier son ratio hauteur/largeur.

### Interdit

```text
LOGO → étiré
LOGO → compressé
```

---

## 9.2 Rotation

Le logo ne doit jamais être :

* incliné ;
* tourné ;
* placé en diagonale ;
* retourné.

Il doit conserver son orientation officielle.

---

## 9.3 Modification des couleurs

Il est interdit de remplacer les couleurs officielles par :

* rouge ;
* vert ;
* jaune ;
* violet ;
* orange ;
* dégradés arbitraires ;
* couleurs personnalisées.

Les seules versions autorisées sont celles définies dans ce document.

---

## 9.4 Effets graphiques

Les effets suivants sont interdits :

* ombre portée ;
* glow ;
* effet 3D ;
* biseau ;
* embossage ;
* reflet ;
* transparence excessive ;
* texture ;
* contour lumineux ;
* effet métallique non officiel.

---

## 9.5 Modification de la typographie

Il est interdit :

* de remplacer la police ;
* de modifier arbitrairement le poids ;
* de changer l'espacement des caractères ;
* d'utiliser une autre typographie ;
* de reconstruire le nom de la marque avec une police similaire.

La typographie officielle doit être respectée.

---

## 9.6 Modification de la composition

Il est interdit de :

* séparer arbitrairement l'icône du nom ;
* modifier les distances entre les éléments ;
* changer l'ordre des éléments ;
* modifier la taille relative de l'icône ;
* déplacer le baseline ;
* supprimer une partie du logo ;
* ajouter un élément au logo.

---

## 9.7 Découpage

Le logo ne doit pas être :

* coupé ;
* masqué ;
* recadré ;
* partiellement caché ;
* placé derrière un autre élément.

---

## 9.8 Mauvaise qualité

Les fichiers basse résolution doivent être évités.

Il est interdit d'utiliser :

* un logo pixellisé ;
* une capture d'écran ;
* une image fortement compressée ;
* une reproduction floue ;
* une version dégradée issue d'une conversion incorrecte.

Lorsque cela est possible, le fichier vectoriel original doit être privilégié.

# 11. Formats de fichiers officiels

Les fichiers officiels doivent être conservés dans des formats adaptés à leur utilisation.

## 11.1 SVG

**Format principal recommandé pour la source vectorielle.**

Utilisations :

* web ;
* interfaces ;
* développement ;
* documents numériques ;
* redimensionnement ;
* impression lorsque le workflow le permet.

Le SVG doit être considéré comme le format vectoriel de référence.

---

## 11.2 PDF vectoriel

Utilisations :

* impression ;
* documents professionnels ;
* transmission à des imprimeurs ;
* archivage ;
* supports institutionnels.

Le PDF doit conserver les éléments vectoriels lorsque le fichier source le permet.

---

## 11.3 PNG transparent

Utilisations :

* web ;
* présentations ;
* réseaux sociaux ;
* intégrations digitales ;
* documents bureautiques.

Le PNG doit disposer d'un fond transparent lorsque cela est nécessaire.

---

## 11.4 ICO

Utilisation :

* favicon ;
* icônes système ;
* applications compatibles.

---

## 11.5 Formats à éviter

Les formats suivants ne doivent pas être utilisés comme fichiers maîtres :

* JPG ;
* GIF ;
* BMP ;
* captures d'écran ;
* images compressées ;
* fichiers provenant de copies d'écran.

> **Les fichiers vectoriels doivent toujours être conservés comme sources principales.**

# 14. Utilisation par des tiers

Les partenaires, fournisseurs, clients, prestataires ou autres tiers qui utilisent le logo Walden Corp doivent respecter intégralement les règles de ce document.

Aucune modification du logo n'est autorisée sans validation.

Les tiers ne doivent pas :

* redessiner le logo ;
* modifier ses couleurs ;
* modifier sa structure ;
* changer sa typographie ;
* créer une nouvelle variante ;
* ajouter des effets ;
* intégrer le logo dans une nouvelle marque sans autorisation.

# 15. Utilisation par une IA

Les systèmes d'intelligence artificielle, outils de génération graphique et logiciels automatisés doivent respecter exactement les règles définies dans ce document.

Lorsqu'une IA doit générer, modifier ou intégrer le logo Walden Corp, les instructions suivantes doivent être respectées.

## 15.1 Règles obligatoires

L'IA doit :

* utiliser uniquement une version officielle ;
* conserver les proportions exactes ;
* conserver les couleurs officielles ;
* respecter la zone de protection ;
* respecter la typographie officielle ;
* conserver la composition ;
* préserver la lisibilité ;
* ne créer aucune nouvelle variante sans autorisation.

---

## 15.2 Interdictions pour l'IA

L'IA ne doit pas :

* réinventer le symbole ;
* modifier la forme du "W" ;
* changer le style du logo ;
* ajouter des effets ;
* modifier la palette ;
* ajouter des éléments décoratifs ;
* générer une version 3D ;
* générer une version cartoon ;
* générer une version futuriste non validée ;
* générer une variante artistique ;
* changer la typographie ;
* modifier le baseline.

---

## 15.3 Instruction de référence

Lorsqu'une instruction destinée à une IA est nécessaire, elle peut être formulée ainsi :

> **Utiliser exclusivement le logo officiel Walden Corp fourni comme référence. Ne modifier ni sa géométrie, ni ses proportions, ni sa typographie, ni sa palette, ni son espacement. Respecter la zone de protection officielle et ne créer aucune nouvelle variante non autorisée.**

---

# 16. Contrôle qualité

Avant toute diffusion, chaque utilisation du logo doit faire l'objet d'un contrôle visuel.

## 16.1 Checklist

Avant publication, vérifier :

* [ ] La bonne version du logo est utilisée.
* [ ] Les proportions sont correctes.
* [ ] Les couleurs sont officielles.
* [ ] La zone de protection est respectée.
* [ ] Le logo est suffisamment grand pour être lisible.
* [ ] Le contraste est suffisant.
* [ ] Aucun élément ne masque le logo.
* [ ] Aucun effet graphique n'a été ajouté.
* [ ] La typographie n'a pas été modifiée.
* [ ] Le fichier possède une qualité suffisante.
* [ ] Le fond ne perturbe pas la lecture.
* [ ] Le logo n'a pas été déformé.
* [ ] La version utilisée correspond au contexte.

---

# 17. Règle générale

Le logo Walden Corp doit toujours apparaître :

**propre, lisible, proportionné, cohérent et conforme à l'identité visuelle officielle.**

Toute personne ou organisation utilisant le logo est responsable du respect de ces règles.

En cas de doute :

1. utiliser la version officielle la plus adaptée ;
2. privilégier la lisibilité ;
3. conserver la zone de protection ;
4. ne pas modifier le logo ;
5. demander une validation avant diffusion lorsqu'une situation n'est pas couverte par ce document.

> **En cas de doute, ne pas modifier le logo. Utiliser le fichier officiel.**
